# Solara

A Windows desktop workspace for AI-assisted software development, by Solarna Systems.

Solara brings project files, conversations, terminal tools, and Git into one application. It is local-first, with configurable model providers; requests to external providers may send selected context off the device.

## Scope

- Project inspection and file navigation.
- Reviewable file changes and command execution.
- Project context, task tracking, and activity views.
- Browser tools with approval controls for page actions.

**Status:** in development. This overview is not a general-release announcement.
